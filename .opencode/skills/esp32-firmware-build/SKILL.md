# ESP32 Firmware Build & Flash Skill

## Overview

This skill automates the complete ESP-IDF development workflow:
1. **Clean** - Remove build artifacts (optional, user-configurable)
2. **Build** - Compile firmware using ESP-IDF
3. **Flash** - Program ESP32 connected via USB
4. **Monitor** - Open serial monitor (optional)

## Use Cases

- **Daily Development**: Quick build-flash cycle with automatic port detection
- **CI/CD Integration**: Scripted firmware builds without user intervention
- **Debugging**: Monitor output directly after flashing
- **Error Diagnosis**: Detailed build failure reports with suggestions

- "Build and flash the ESP32 firmware"
- "Compile and program ESP32"

## Step-by-Step Workflow

### Prerequisites
- ESP32 connected via USB (appears as `/dev/ttyUSB0`, `/dev/ttyACM0`, or `COM3+` depending on OS)
- ESP-IDF environment configured (`idf.py` available in PATH)
- Working directory: project root containing `esp32_firmware/` directory

### Workflow Steps

1. **Detect Serial Port**
   - Auto-detect ESP32 serial port
   - If multiple ports, prompt user to select
   - Validate port connectivity (send AT command or echo test)

2. **Clean Build (Optional)**
   - If user requests: `idf.py fullclean` to remove all build artifacts
   - Useful when switching between firmware versions or after failed builds

3. **Build Firmware**
   - Execute: `idf.py build` from `esp32_firmware/` directory
   - Parse compiler output for warnings/errors
   - If build fails: capture error, suggest fixes (missing components, config issues)
   - If build succeeds: report binary size and memory usage

4. **Flash to ESP32**
   - Execute: `idf.py flash` to program ESP32
   - Monitor progress and report flashing status
   - If flash fails: suggest troubleshooting (USB driver, baud rate, port permissions)

5. **Open Serial Monitor (Optional)**
   - If user requests: `idf.py monitor` to view ESP32 output
   - Can be skipped for automated builds
   - Press `Ctrl+]` to exit monitor (or `Ctrl+C` on Windows)

## Configuration Options

```bash
# Build with full rebuild (no incremental)
esp32-firmware-build --clean

# Build and flash without monitor
esp32-firmware-build --no-monitor

# Build specific component only (optional optimization)
esp32-firmware-build --component fan_control

# Specify serial port explicitly
esp32-firmware-build --port /dev/ttyUSB0

# Disable auto-detection and use default port
esp32-firmware-build --port default
```

## Error Handling

### Common Errors & Recovery

| Error | Cause | Solution |
|-------|-------|----------|
| `"idf.py: command not found"` | ESP-IDF not in PATH | Source ESP-IDF setup script: `. $IDF_PATH/export.sh` (Linux) or `. $IDF_PATH/export.ps1` (Windows) |
| `"No ESP32 board found"` | USB not connected or driver missing | Check USB cable, install CH340 driver (Windows), verify with `ls /dev/ttyUSB*` |
| `"Build failed: component not found"` | Missing esp-idf submodule | Run `idf.py reconfigure` or reinstall ESP-IDF |
| `"Flash verification failed"` | Corrupted binary or port disconnected | Retry flash, check USB connection, inspect `build/bootloader.bin` |
| `"Permission denied /dev/ttyUSB0"` | User not in dialout group (Linux) | Run `sudo usermod -a -G dialout $USER` |

### Build Output Parsing

- ✅ **Green**: Build succeeded, binary ready
- ⚠️ **Yellow**: Warnings detected (memory usage, deprecated functions)
- ❌ **Red**: Build failed, error details shown

### Memory Report

After successful build, display:
```
Flash: 1.2 MB / 4.0 MB (30%)
IRAM:  156 KB / 192 KB (81%)
DRAM:  234 KB / 320 KB (73%)
```

## Hardware Notes

**ESP32-WROOM-32 GPIO Safety**:
- ✅ GPIO26 (PWM/DAC_2) - Fan output
- ✅ GPIO34 (ADC input) - Temperature sensor (Phase 1-3+)
- ✅ GPIO21/22 (I2C) - INA219 current sensor (Phase 3+ only)
- ✅ GPIO27 (TOUCH7) - Tachometer input (Phase 3+ optional)
- ⚠️ GPIO6-11 - **RESERVED** for flash memory (DO NOT USE)
- ⚠️ GPIO12-15 - **RESERVED** for JTAG debugging (avoid during JTAG)

```bash
idf.py list-apps

# View ESP32 chip info

# Erase entire flash and reflash
idf.py erase-flash
idf.py flash

# Get build configuration
idf.py reconfigure
```
